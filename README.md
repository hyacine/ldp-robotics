# First France Challenge Website

Welcome to the First France Challenge website project! This project is dedicated to showcasing the First France Challenge, a robotics competition that encourages innovation, teamwork, and technical skills among participants.

## Project Structure

The project is organized as follows:

```
first-france-challenge-website
├── src
│   ├── index.html          # Main entry point of the website
│   ├── pages               # Contains all the individual pages
│   │   ├── home.html       # Home page
│   │   ├── about.html      # About page
│   │   ├── teams.html      # Teams page
│   │   ├── schedule.html    # Schedule page
│   │   ├── rules.html      # Rules page
│   │   └── contact.html     # Contact page
│   ├── components          # Reusable components
│   │   ├── header.html     # Header component
│   │   └── footer.html     # Footer component
│   ├── styles              # CSS styles
│   │   └── main.css        # Main stylesheet
│   ├── scripts             # JavaScript files
│   │   └── main.js         # Main script
│   └── data                # Data files
│       └── teams.json      # JSON data for teams
├── public                  # Public files
│   └── robots.txt         # Robots.txt for SEO
├── package.json            # NPM configuration
├── .gitignore              # Git ignore file
├── README.md               # Project documentation
└── LICENSE                 # Licensing information
```

## Setup Instructions

1. **Clone the repository:**
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory:**
   ```
   cd first-france-challenge-website
   ```

3. **Install dependencies:**
   ```
   npm install
   ```

4. **Run the project:**
   You can use a local server to view the website. For example, you can use `live-server` or any other local server of your choice.

## Features

- **Home Page:** An overview of the competition and its significance.
- **About Page:** Detailed information about the First France Challenge.
- **Teams Page:** A showcase of the participating teams.
- **Schedule Page:** A detailed schedule of the events.
- **Rules Page:** Outlines the competition rules.
- **Contact Page:** Provides contact information and a form for inquiries.
